# 📩 SMS Spam Classifier

A machine learning-based SMS/email classification system that distinguishes between **spam** and **non-spam (ham)** messages using Natural Language Processing (NLP) techniques. The app is built with Streamlit for an interactive user interface.

---

Overview

This project uses a dataset of labeled SMS messages to train a spam detection model. It applies standard NLP preprocessing and uses a machine learning classifier to predict whether new messages are spam or not.

---

Features

- Clean and interactive **Streamlit web interface**
- Text preprocessing with:
- Lowercasing
- Stopword removal
- Punctuation removal
- Feature extraction using **TF-IDF**
- Machine learning with **Naive Bayes** (or Logistic Regression)
- Real-time prediction on user input
